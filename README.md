# GT Shuttle

GT Shuttle 是一个面向移动端的校园接驳车查询 PWA，提供南校区与北校区之间的双向班次、日期筛选、路线时间轴和基于时刻表的到站时间估算。

## 功能

- 等距地图同时展示两个方向，点击方向卡片或车辆查看详情
- 查看今天和未来 14 天班次
- 根据星期自动过滤有效班次
- 基于固定行驶时间展示班车运行状态和预计到站时间
- 19:30 后切换夜间路线（南校区 9 号门关闭）
- 点击班次进入预览模式，再恢复实时视图
- 中英文界面切换
- 支持安装为手机桌面 PWA，并提供离线缓存
- 保留 `public/lite.html` 作为旧设备降级页面

## 技术栈

## 本地开发

需要 Node.js 18+。

```bash
npm install
npm run dev
```

然后打开终端提示的本地地址。

### 动画测试

动画回归检查覆盖双向发车、常规与 red 同刻发车、途经站短停、到站淡出、夜间路线和方向聚焦。运行方式：

点击地图上的车辆会直接放大并跟随，候车车辆也可选中；点击“查看全程”、取消选择或车辆到达终点后恢复路线全景。夜间全景自动聚焦 2 号门和北校大门，隐藏关闭的 9 号门标签；尚有白天班次在运行时保留完整路线。夜间班次预览也使用两站取景，白天预览和未来日期恢复完整地图。

地图使用统一时钟和逐帧 SVG 动画，车辆提前 30 秒出现，途经站停留 6 秒，终点停留 8 秒后用 2 秒淡出。站点到达时间仍来自原有配置。默认全景；点中运行车辆后可跟随，终点到站后自动回全景。未来日期和班次预览使用静态路线。

```bash
npm run test:animation
```

此检查覆盖七个星期类型的班次动画边界、转弯连续性、同刻 red 发车和时钟暂停/后台恢复。性能测试页面为开发服务下的 `/scripts/perf-fixture.html`，包含四辆车、20×播放的合成压力场景，不修改正式时刻表，也不会包含在生产入口中。

## 添加到主屏幕

微信内首次访问不自动提示，从第二次新访问开始，引导使用手机浏览器打开。外部手机浏览器会在每次新访问时显示对应的添加步骤；支持原生安装的浏览器可点击按钮确认安装。提示在页面加载后延迟 2 秒出现，同次访问中关闭、刷新或历史返回不会重复弹出。

也可随时点击页脚的“添加到主屏幕”查看步骤。关闭提示只影响当前访问；点击“3 天内不再提醒”会在当前浏览器暂停自动提示 72 小时，期间仍可从页脚手动打开。从桌面图标以独立应用模式启动，或本浏览器已观察到安装完成后，不再自动提醒。安装引导逻辑位于 `hooks/useInstallGuide.ts`，界面位于 `components/PWAPrompt.tsx`。Lite 页面保持原有功能。

## 配置位置

首页两张校区卡片始终显示下一班发车时间、倒计时、实际出发门及后续两个不同发车时刻。同刻普通／red 班次合并显示数量，完整时刻表仍逐班列出。手机端两张卡片在底部等宽并排：上方为校区和出发门，大时间与倒计时同排，下方纵向列出后续两班；窄屏使用简短倒计时。点击卡片选择方向，上划或点击顶部拖动条平滑展开站点和完整时刻表，下划收起；展开后保留双校区紧凑摘要。站点详情与时刻表位于同一个滚动面板内。点击车辆时在地图内显示到站信息，发车卡片不受影响。地图站点突出发车时间和倒计时，并明确区分途经站预计到站时间。桌面端保留顶部并排卡片和侧栏详情。已发车时间放在展开详情内；未来日期显示当日首班，不显示实时倒计时。

- `config/schedules.ts`：双向班次和运行日期
- `config/stations.ts`：日间/夜间站点与预计行驶时间
- `locales.ts`：中英文文案
- `public/icon.svg`：主屏幕图标源文件；导出为 `icon-192.png`、`icon-512.png` 和 180px 的 `apple-touch-icon.png`，保持完整、不透明的背景和车身四周留白
- `public/favicon.svg`：小尺寸网页图标源文件；导出为 `favicon.png`（32px）和 `favicon.ico`（16/32/48px）
- `hooks/useShuttleState.ts`：页面状态与实时派生数据
- `lib/shuttle.ts`：班次、路线和时间计算逻辑
- `lib/mapGeometry.ts`、`lib/mapTraffic.ts`：曲线路径、班次生命周期与车辆位置计算
- `lib/playbackClock.ts`：真实/模拟时钟与逐帧订阅

## 部署

项目使用 `wrangler.json` 配置 Cloudflare Workers 静态资源部署。先构建，再使用 Wrangler 发布 `dist/`。

## 数据说明

应用不接入 GPS 或后端实时车辆接口，页面中的“实时”状态是根据时刻表和固定行驶时长计算的估算结果。实际发车、路况和到站时间请以现场情况为准。
